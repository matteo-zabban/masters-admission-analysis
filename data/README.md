# Dataset setup

The original analysis uses the **Graduate Admission 2** dataset, with 500 observations, sourced from Kaggle and described as CC0 in the academic report.

Download the 500-row dataset from its original provider and save it at the repository root as:

`Admission_Predict_Ver1.1.csv`

The CSV is not bundled here. The R script uses a relative path, so run it with the repository root as the working directory (or adapt the path locally).
